# Dashboard do treinador

`/dashboard` é o cockpit do clube. Carrega equipe, elenco, histórico de transferências, configurações, notícias e partidas para priorizar próximo jogo e pendências.

## Áreas atuais

- próximo jogo e tarefas de confirmação/teto;
- elenco por setor, perfil, salário, dispensa e envio a leilão;
- editor de formação/escalação armazenado no time;
- visão geral com estatísticas/notícias;
- resumo financeiro e upload de escudo quando permitido em `settings`.

O objetivo correto é “o que preciso fazer hoje”. Evite ampliar esta tela como mural: dados secundários devem ir para uma rota própria ou ser carregados sob demanda.
